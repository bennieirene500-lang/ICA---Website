# ICA Website Project

## Files

- `index.html` — main homepage
- `free-training.html` — matching internal free training page
- `explore-ica.html` — matching internal ICA information page
- `css/styles.css` — shared website styling
- `js/main.js` — shared mobile menu and utility JavaScript
- `assets/images/` — website image assets

## Publish on Netlify

Upload the entire `ica-website-project` folder or the ZIP file.

Do not upload only `index.html`. The CSS, JavaScript, images and internal pages must remain in the same folder structure.

## Internal links

These are already connected:

- `index.html` → `free-training.html`
- `index.html` → `explore-ica.html`
- Both internal pages link back to `index.html`
